## Conventions

- Project settings are applied by code (`Utsav > Setup`), so a clean clone is reproducible and CI can run it.
- Phase 1 scenes and prefabs are generated by `SpikeSceneBuilder` and `SpikeEffectFactory`. Edit the
  builder, not the generated assets.
- Tests live in `Assets/_Game/Tests/` rather than a root `Tests/` folder (PRD 13.2), because Unity only
  compiles test assemblies inside `Assets/` or packages.
- Assembly definitions: `UtsavNights.Core` (no engine references, unit-testable), `UtsavNights.Spikes`,
  `UtsavNights.Editor`, `UtsavNights.Tests.EditMode`.
- Minimum Android API 26 (Android 8.0), matching the PRD compatibility row. Revisit with Play Console data.
- Package id `com.ankitsharma.utsavnights`. Change it before the first Play upload if the store name changes;
  it cannot change after publishing.
- Active Input Handling is the Input System package only.
- Unity splash screen is off (allowed for Unity 6 Personal [Verify]); the app's own splash comes in Phase 3.
