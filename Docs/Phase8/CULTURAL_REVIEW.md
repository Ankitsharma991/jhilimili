# Phase 8 cultural review list

PRD 19 Phase 8 asks for "two additional environments with cultural review". Before release, reviewers familiar with each
place check the environments below: the layout, the houses, the landmarks, the people and the festival details. Everything
is generic and procedural (LICENCE_LOG own-009). No real street, village or ghat is copied.

Mark each row **OK**, **Change** (with a note) or **Remove**. Rows marked Change or Remove go into the feedback round
after all PRD features are built.

## Town lane (north India, Diwali)

| Item | Questions for the reviewer | Verdict |
|---|---|---|
| The lane and the chowk | Two-storey houses on one side, an open chowk across the lane: does it read as a north Indian town neighbourhood? | |
| House styles | Flat roofs, roof terraces with chhatris, a few tiled roofs; iron, jharokha and wooden balconies; shuttered, arched and jali windows. | |
| Chowk platform with diyas | A raised stone platform at the chowk's end. Is a platform like this common? Should it be a small shrine instead, or nothing? | |
| Neighbours' decorations | Diyas on the plinth, a mango-leaf toran over the door, string lights under the cornice, lotus or geometric rangoli, a star lantern. | |
| Temple spire (far landmark) | A generic shikhara with a saffron flag, far behind. Respectful at that distance? | |

## Hill village (Nepal, Tihar)

| Item | Questions for the reviewer | Verdict |
|---|---|---|
| House styles | Brick and timber, sloping tiled roofs, wooden lattice balconies, jali windows. Does it read as a Nepali hill village? Is anything Newari or Kathmandu-specific that would be wrong elsewhere? | |
| The threshing ground | The open space is a village threshing ground. Is that a natural place to gather and light fireworks for Tihar? | |
| Chautari with a pipal tree | A stone resting platform round a pipal tree with diyas round its edge. Is lighting diyas there appropriate? | |
| Neighbours' decorations | Tihar mandala floor art, diya-ring rangoli, marigold garlands. What is missing that Nepali players expect first (a Laxmi footprint path from the door, marigold garlands on the gate, sel roti)? | |
| The hills | Layered ridges behind the village. | |

## Riverside ghat (east India, Diwali / Dev Deepawali)

| Item | Questions for the reviewer | Verdict |
|---|---|---|
| The ghat | Stone steps down to the river; the open space above is the ghat. Does it read as a ghat town (inspired by the Ganga ghats)? | |
| Floating diyas | Diyas on leaf boats drifting on the river. Is the game's festival framing right (Dev Deepawali is a separate day)? | |
| Fireworks at a ghat | Lighting fireworks on a ghat: acceptable, or should the ghat spot be for diyas and sparklers only? | |
| No far landmarks | The temple and water tank are hidden here (they would stand in the river). Should the far bank have its own temple silhouettes? | |

## People and life (all environments)

| Item | Questions for the reviewer | Verdict |
|---|---|---|
| Neighbours and the crowd | Ambient people use the avatar presets (Phase 6). Is the mix right for each place? | |
| Distant bursts | Neighbours' fireworks far away. | |
| Night Timeline | The evening runs from 6:30 pm to 1 am over the session. Is a late-night end to fireworks realistic, or should it end earlier? | |

## Celebration spots

- Rooftop, balcony, outside the gate, the street, the open space, the empty plot. Is any spot culturally odd for fireworks
  (for example the ghat, or a neighbour's gate)?
- The street allows rockets only from launch pads. Is that clear enough without visible pads?
